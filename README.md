# Wie isses?

Eine Umfrage für Grundschulkinder am Tablet. Jede Frage kommt als Bild, als Text und wird
vorgelesen, damit auch Kinder, die noch nicht lesen können, allein antworten. Oben gibt es
farbige Tabs, einen pro Thema (Essen, Hausaufgaben, Miteinander, Spielen & Basteln, …), mit
wenigen Kernfragen. An einstellbaren Wochentagen kommen ausführlichere Fragen dazu.

- **Geheimzeichen statt Namen:** Jedes Kind sucht sich einmal Tier, Farbe und Obst aus. Pro
  Thema zählt eine Antwort pro Tag.
- **Nur freigeschaltete Tablets** können abstimmen.
- **Admin-Bereich** (`/admin/`, Passwort): Auswertung als Diagramme im Zeitverlauf mit
  Vergleich zum Vorzeitraum, Filter nach Klasse, CSV-Export. Fragen, Bilder und eigene
  Sprachaufnahmen lassen sich bearbeiten. Tablets und Einstellungen werden hier verwaltet.
